# Welcome to WireGuard Easy

You have found the easiest way to install & manage WireGuard on any Linux host!

WireGuard Easy is an all-in-one solution that combines WireGuard VPN with a modern, intuitive web-based management interface. Whether you're setting up a personal VPN or managing multiple clients, WireGuard Easy simplifies the entire process.

## Key Features

WireGuard Easy packs powerful features into an easy-to-use package:

- **All-in-one**: WireGuard + Web UI in a single container
- **Easy installation**: Simple to deploy and even simpler to use
- **Full client management**: List, create, edit, delete, enable & disable clients
- **QR code generation**: Show a client's QR code for easy mobile setup
- **Configuration download**: Download client configuration files
- **Connection statistics**: See which clients are connected in real-time
- **Bandwidth monitoring**: Tx/Rx charts for each connected client
- **Gravatar support**: Personalize your interface
- **Automatic theming**: Light / Dark Mode based on system preferences
- **Multilanguage support**: Use WireGuard Easy in your preferred language
- **One-time links**: Share temporary access links
- **Client expiration**: Automatically disable clients after a set date
- **Prometheus metrics**: Monitor your VPN with industry-standard metrics
- **IPv6 support**: Full IPv6 compatibility
- **CIDR support**: Flexible network configuration
- **2FA support**: Enhanced security with two-factor authentication

## Quick Start

Get up and running in just a few steps:

<Steps>
  <Step title="Install Docker">
    Install Docker on your Linux host:
    
    ```bash
    curl -sSL https://get.docker.com | sh
    ```
  </Step>
  
  <Step title="Deploy WireGuard Easy">
    Download and start WireGuard Easy with Docker Compose:
    
    ```bash
    sudo mkdir -p /etc/docker/containers/wg-easy
    sudo curl -o /etc/docker/containers/wg-easy/docker-compose.yml \
      https://raw.githubusercontent.com/wg-easy/wg-easy/master/docker-compose.yml
    cd /etc/docker/containers/wg-easy
    sudo docker compose up -d
    ```
  </Step>
  
  <Step title="Access Web UI">
    Open your browser and navigate to `http://your-server-ip:51821` to complete the setup wizard.
  </Step>
  
  <Step title="Create Your First Client">
    Use the web interface to create your first VPN client and download the configuration or scan the QR code.
  </Step>
</Steps>

<Note>
For production deployments, it's strongly recommended to set up a reverse proxy with HTTPS. See our [Getting Started](/getting-started) guide for detailed instructions.
</Note>

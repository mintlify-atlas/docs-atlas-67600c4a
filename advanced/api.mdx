## Overview

The WireGuard Easy API provides programmatic access to manage your WireGuard server, clients, and configuration. All endpoints use REST principles with JSON request/response bodies.

<Warning>
  The API is currently in development and subject to change. Monitor release notes for breaking changes.
</Warning>

## Base URL

All API endpoints are accessible at:

```
https://your-domain:51821/api
```

## Authentication

The API uses HTTP Basic Authentication with your WireGuard Easy username and password.

<Warning>
  If 2FA (TOTP) is enabled on your account, API authentication will fail. Disable 2FA to use the API.
</Warning>

### Authentication Example

<CodeGroup>
```bash cURL
curl -u username:password \
  https://example.com:51821/api/client
```

```python Python
import requests
from requests.auth import HTTPBasicAuth

url = "https://example.com:51821/api/client"
response = requests.get(url, auth=HTTPBasicAuth('username', 'password'))

if response.status_code == 200:
    data = response.json()
    print(data)
else:
    print(f"Error: {response.status_code}")
```

```javascript JavaScript
const username = 'your-username';
const password = 'your-password';
const credentials = Buffer.from(`${username}:${password}`).toString('base64');

fetch('https://example.com:51821/api/client', {
  headers: {
    'Authorization': `Basic ${credentials}`
  }
})
  .then(response => response.json())
  .then(data => console.log(data));
```
</CodeGroup>

## Session Management

### Login

Create a new session.

```http
POST /api/session
```

<ParamField body="username" type="string" required>
  Username for authentication
</ParamField>

<ParamField body="password" type="string" required>
  Password for authentication
</ParamField>

<ParamField body="remember" type="boolean">
  Whether to create a persistent session
</ParamField>

<ParamField body="totpCode" type="string">
  TOTP code if 2FA is enabled
</ParamField>

<ResponseField name="status" type="string">
  Login status: `success`, `TOTP_REQUIRED`, or `INVALID_TOTP_CODE`
</ResponseField>

<CodeGroup>
```bash cURL
curl -X POST https://example.com:51821/api/session \
  -H "Content-Type: application/json" \
  -d '{
    "username": "admin",
    "password": "your-password",
    "remember": true
  }'
```

```json Response
{
  "status": "success"
}
```
</CodeGroup>

### Get Current Session

Retrieve information about the current authenticated user.

```http
GET /api/session
```

<ResponseField name="id" type="number">
  User ID
</ResponseField>

<ResponseField name="username" type="string">
  Username
</ResponseField>

<ResponseField name="name" type="string">
  Display name
</ResponseField>

<ResponseField name="email" type="string">
  Email address
</ResponseField>

<ResponseField name="role" type="string">
  User role (e.g., `admin`, `user`)
</ResponseField>

<ResponseField name="totpVerified" type="boolean">
  Whether TOTP 2FA is enabled and verified
</ResponseField>

### Logout

Delete the current session.

```http
DELETE /api/session
```

<ResponseField name="success" type="boolean">
  Whether the logout was successful
</ResponseField>

<ResponseField name="success" type="boolean">

  https://example.com:51821/api/client/1/configuration

### Manage 2FA (TOTP)

Manage Time-based One-Time Password (TOTP) two-factor authentication.

```http

```

#### Setup TOTP

<ParamField body="type" type="string" required>
  Set to `setup` to initialize TOTP
</ParamField>

<ResponseField name="success" type="boolean">
  Whether setup was successful
</ResponseField>

<ResponseField name="type" type="string">
  Response type: `setup`
</ResponseField>

<ResponseField name="key" type="string">
  Base32-encoded TOTP secret key
</ResponseField>

<ResponseField name="uri" type="string">
  TOTP URI for QR code generation
</ResponseField>

#### Enable TOTP

<ParamField body="type" type="string" required>
  Set to `create` to enable TOTP
</ParamField>

<ParamField body="code" type="string" required>
  Current TOTP code to verify setup
</ParamField>

<ResponseField name="success" type="boolean">
  Whether TOTP was enabled successfully
</ResponseField>

<ResponseField name="type" type="string">
  Response type: `created`
</ResponseField>

#### Disable TOTP

<ParamField body="type" type="string" required>
  Set to `delete` to disable TOTP
</ParamField>

<ParamField body="currentPassword" type="string" required>
  Current password for verification
</ParamField>

<ResponseField name="success" type="boolean">
  Whether TOTP was disabled successfully
</ResponseField>

<ResponseField name="type" type="string">
  Response type: `deleted`
</ResponseField>

<CodeGroup>
```bash Setup TOTP
curl -X POST https://example.com:51821/api/me/totp \
  -u admin:password \
  -H "Content-Type: application/json" \
  -d '{"type": "setup"}'
```

```bash Enable TOTP
curl -X POST https://example.com:51821/api/me/totp \
  -u admin:password \
  -H "Content-Type: application/json" \
  -d '{
    "type": "create",
    "code": "123456"
  }'
```

```bash Disable TOTP
curl -X POST https://example.com:51821/api/me/totp \
  -u admin:password \
  -H "Content-Type: application/json" \
  -d '{
    "type": "delete",
    "currentPassword": "your-password"
  }'
```
</CodeGroup>

## Error Responses

All endpoints return standard HTTP status codes:

| Status Code | Description |
|-------------|-------------|
| 200 | Success |
| 201 | Created |
| 400 | Bad Request - Invalid parameters |
| 401 | Unauthorized - Authentication required or failed |
| 403 | Forbidden - Insufficient permissions |
| 404 | Not Found - Resource doesn't exist |
| 500 | Internal Server Error |

Error responses include a message:

```json
{
  "statusCode": 404,
  "statusMessage": "Client not found"
}
```
